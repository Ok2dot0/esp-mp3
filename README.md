# ESP MP3

Work in progress: an ESP-based MP3 player project developed with PlatformIO.

## Status

This project is currently under active development. Features, hardware requirements,
and the software interface may change.

## Overview

The goal of this project is to build a standalone MP3 player using an ESP
microcontroller. More details will be added as the implementation develops.

## Building

This project uses [PlatformIO](https://platformio.org/).

1. Clone the repository.
2. Open the project in PlatformIO or Visual Studio Code with the PlatformIO extension.
3. Connect the target ESP board.
4. Build and upload the project:

	```sh
	pio run --target upload
	```
